# ADR-0007 — Room 3

Status: Accepted · 2026-07-27 (supersedes the persistence library in ADR-0004)

## Context

ADR-0004 named Room before any data layer existed. Room 2 is Android only and
in maintenance. Room 3 is the multiplatform line, with a KSP compiler and
SQLite drivers that can be swapped. The data layer is written for source sets
that will move to shared code.

## Decision

- Storage is Room 3 (`androidx.room3`), not Room 2.
- Code generation runs through KSP. The Room 3 Gradle plugin owns the schema
  export folder.
- The DAO speaks entity types only. Mapping between entity and domain lives in
  the repository implementation, which is the one seam between the two shapes.
- Saving is `@Upsert`, so create and edit are one operation. Delete is by id
  and gives the same result when it runs twice.
- Enum columns use the built in converters.

## Consequences

- The data layer moves to a shared source set without a rewrite. Only the
  driver is exchanged at that step.
- Package names differ from Room 2, so going back is an import change in every
  data layer file.
- Schema JSON is exported from version 1 onward, which ADR-0012 depends on.

## Reverse cost

Moderate. The API is the same but the coordinates are not, so a move back to
Room 2 touches every data layer import and drops the shared path.
