# ADR-0007 — Room 3

Status: Accepted · 2026-07-27 (supersedes the persistence library in ADR-0004)

## Context

ADR-0004 named Room as the persistence library before any data layer existed.
Room 2.x is Android-only and in maintenance; Room 3 is the multiplatform line,
published under `androidx.room3` with a KSP compiler and pluggable SQLite
drivers. ADR-0003 makes the database the single source of truth, and the data
layer is written for source sets that move to shared multiplatform code.

## Decision

- Persistence is Room 3 (`androidx.room3`), not Room 2.x.
- Code generation runs through KSP; the `androidx.room3` Gradle plugin owns the
  schema export directory.
- The DAO speaks entity types only; entity↔domain mapping lives in the
  repository implementation, which is the single seam between the two shapes.
- Saving is `@Upsert` — create and edit are one operation. Delete is by id and
  idempotent.
- Enum columns use built-in converters; no hand-written type converters.

## Consequences

- The data layer moves to a shared source set without a rewrite; only the
  Android driver is exchanged for a platform driver at that step.
- Artifact coordinates and package names differ from Room 2.x, so reverting is a
  dependency-and-import change across every data-layer file.
- Schema JSON is exported from version 1 onward, which ADR-0012 relies on.

## Reverse cost

Moderate: the API surface is unchanged but the coordinates are not, so a move
back to Room 2.x touches every data-layer import and drops the shared-target path.
